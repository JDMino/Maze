# 🧩 Laberinto (Juego Web)

Pequeño juego de laberinto desarrollado con JavaScript puro, enfocado en la simplicidad y la recreación.

## 🎮 Descripción

El objetivo es simple: encontrar la salida del laberinto sin ser atrapado por los enemigos.

Cada partida genera un laberinto diferente, lo que hace que cada intento sea único.

## 🚀 Características

- Generación procedural de laberintos
- Movimiento con teclado (WASD / flechas)
- Controles táctiles para dispositivos móviles
- Enemigos con movimiento dinámico
- Sistema de tiempo
- Pantallas de victoria y derrota
- Diseño responsive

## 📱 Controles

### PC
- Flechas del teclado
- WASD

### Mobile / Tablet
- Botones táctiles en pantalla

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (Canvas API)

## 🤖 Sobre el desarrollo

Este proyecto fue desarrollado como una experiencia de aprendizaje y experimentación, utilizando herramientas de asistencia como ChatGPT para apoyar en la lógica, estructura y mejoras del código.

## ⚠️ Estado del proyecto

El juego se encuentra en desarrollo y tiene un enfoque simple, pensado principalmente para recreación y práctica.

No es un producto final ni comercial.

## 📌 Posibles mejoras futuras

- Sistema de niveles
- IA más avanzada para enemigos
- Sonidos y música
- Mejoras visuales
- Guardado de puntajes

1. Clonar el repositorio
2. Abrir `index.html` en el navegador
